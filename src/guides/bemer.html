Running a session

Same steps for every piece
  1. Switch on: hold any button for about 1½ seconds.
  2. Start: tap P1, P2 or P3 once. That program's light pulses while it runs.
  3. Stay with the horse. It stops by itself when the time is up.
  4. Stop early: hold any button for 1½ seconds. Left alone, it switches off after 2 minutes.
  5. Check it off on the Tasks tab, with a note if the horse was fidgety or unusually relaxed.
